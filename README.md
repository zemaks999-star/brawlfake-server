# Сервер для Brawl Clone (бесплатно, Render)

Сервер хранит комнаты и сам считает игру, игроки только шлют управление и получают картинку.

## Запуск на Render (бесплатно, без карты)
1. Создайте на github.com пустой репозиторий и загрузите в него все файлы из этой папки (`server.js`, `hub.js`, `game-core.js`, `package.json`).
2. На render.com: **New → Web Service** → выберите репозиторий.
3. Настройки: Runtime **Node**, Build Command `npm install`, Start Command `npm start`, Instance Type **Free**. Регион лучше Frankfurt.
4. Когда сервис запустится, адрес будет вида `https://имя.onrender.com`. В игре на вкладке «Лобби» впишите `wss://имя.onrender.com`
   (или впишите его в начале `brawl.html` в `DEFAULT_SERVER`, тогда он будет у всех сразу).

Бесплатный сервер засыпает после 15 минут без трафика и просыпается около минуты. Перед игрой откройте адрес сервера в браузере, чтобы разбудить его.

## Если изменили игровую логику в brawl.html
Пересоберите `game-core.js`: `node make-core.js ../brawl.html` и загрузите его в репозиторий.

## Локальная проверка
`npm install && npm start`, адрес в игре `ws://localhost:8080`.
